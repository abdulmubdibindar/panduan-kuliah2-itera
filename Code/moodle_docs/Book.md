# Book

> Sumber: https://docs.moodle.org/502/en/Book

Books allow teachers to create multi-page resources with a book-like format and table of contents. The resource supports embedded multimedia and offers a printing option. Students can navigate using arrows, text links, or the table of contents. Teachers can hide individual pages/chapters from students while retaining visibility themselves.

## How is it set up?

1. Select **Book** from the activity chooser.
2. Add a **Name** and optional **Description**.
3. Configure appearance settings.
4. Expand additional settings as needed.
5. Add content to the first chapter.
6. Use the "+" icon in the table of contents to add further chapters.

## Content support

A Book can embed images, videos, sound, and H5P content into its chapters. Students may export a book's content as a PDF through the gear icon.
