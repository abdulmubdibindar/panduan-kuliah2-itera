# URL

> Sumber: https://docs.moodle.org/502/en/URL

A URL (Uniform or Universal Resource Locator) is a link on the internet to a website or online file. Teachers use this resource to give students web links for research or reference.

## How is it set up?

1. Enable editing in the course, select **URL** from the activity chooser, and provide a descriptive **Name**.
2. Enter the web address in the **External URL** field, including the full protocol (`https://`).
3. Configure display settings in the **Appearance** section.
4. Adjust additional settings as needed and save.

## How does it work?

**Student view**: students click the icon to access the website or external file; the display format (same window, new window, embedded, etc.) is determined by the teacher's settings and site configuration.

**Teacher view**: teachers can modify the URL's settings by clicking the link and opening **Settings**, even when editing mode is disabled.
