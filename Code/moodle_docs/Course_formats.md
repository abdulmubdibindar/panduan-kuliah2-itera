# Course_formats

> Sumber: https://docs.moodle.org/502/en/Course_formats

A course format refers to the layout of a course. Teachers can select a course format from **Course navigation → Settings → Course format**.

## Standard course formats

- **Custom sections** — the course is divided into customisable sections that a teacher can give titles to. Content and activities can be added in each section. This format works well for objective-based courses where topics require varying amounts of time.
- **Weekly sections** — the course is organised into sections corresponding to each week of the course, starting from the course start date. This format suits courses where all students engage with materials at the same time. The course start date must be correct for the weekly labels to be accurate.
- **Single activity** — the course has only one section and allows the teacher to add exactly one activity to the course.

Weekly and Custom sections both support a "Show one section per page" display option. When enabled, the course home page shows just the section names, any text in the section description, and activity/resource counts, instead of the full section content.

For students who begin a course at different times, Moodle offers a **Course relative dates** feature that displays dates relative to each student's own start date rather than a fixed calendar date.

## Management

Administrators manage which course formats are available and their display order to teachers through Site administration.
