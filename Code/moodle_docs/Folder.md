# Folder

> Sumber: https://docs.moodle.org/502/en/Folder

The folder allows a teacher to display several course files together. Files may be uploaded individually or as a zipped folder that gets unzipped automatically. A folder can only be used for gathering and displaying files, not other resources or activities.

## How is it set up?

Two methods are available:

1. Drag and drop a compressed (zipped) folder into a course section, then select **Unzip files and create folder**.
2. Use the activity chooser to create a folder, then:
   - Provide a **Name** and optional **Description**.
   - Upload the desired files in the **Content** section.
   - Configure display settings and choose whether to include a download-all button.
   - Save the folder.

## How does it work?

**Student view**: students either click the folder to view its files or see the files displayed directly on the course page, depending on the display setting. A download option lets students download the files as a single zipped folder for offline viewing. Images and HTML files can display directly in the browser.

**Teacher view**: teachers use an **Edit** button to upload, edit, or remove files from the folder.
