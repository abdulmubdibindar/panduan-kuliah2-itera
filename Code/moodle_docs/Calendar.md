# Calendar

> Sumber: https://docs.moodle.org/502/en/Calendar

The calendar can display site, course, group, user, and category events, in addition to assignment and quiz deadlines, chat times, and other course events.

## Event management

New events may be added either by clicking a button or by clicking into an empty space on the desired day. When adding, editing, or deleting an event, the event opens in a pop-up window.

## Event manipulation

Events created manually may be dragged and dropped to a different date, as can events generated by the Feedback, Assignment, and Choice activities. For activity-generated events, dragging the calendar event to a new date also changes the corresponding date inside the activity itself (e.g. dragging an Assignment's due-date event changes the assignment's **Due date** setting).

## Integration

A calendar can be embedded in a course page or the site front page by adding a **Calendar block** or an **Upcoming events block**.
