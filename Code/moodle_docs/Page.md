# Page

> Sumber: https://docs.moodle.org/502/en/Page

A page resource creates a link to a screen that displays content created by the teacher, using Moodle's text editor. The content can include plain text, images, audio, video, embedded code, or a combination of these.

## How is it set up?

1. Select **Page** from the activity chooser while editing is enabled.
2. Provide a **Name** and optional **Description**.
3. Add content (text, images, links, multimedia) in the **Content** section.
4. Configure appearance settings, such as displaying the last-modified date.
5. Adjust additional settings as needed and select **Save and display**.

## How does it work?

**Student view**: students click the page's icon to view the content the teacher created.

**Teacher view**: teachers modify a page by selecting the resource and opening **Settings**.
