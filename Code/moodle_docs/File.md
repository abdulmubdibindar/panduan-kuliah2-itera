# File

> Sumber: https://docs.moodle.org/502/en/File

Files are not just materials such as word-processed documents or slideshow presentations. All types of files can be uploaded and accessed through Moodle, but the student needs to have the correct software to be able to open them.

## How is it set up?

Two approaches exist for adding a File resource:

1. Drag and drop a file directly onto the course page.
2. Select **File** from the activity chooser.

When using the activity chooser method, the teacher should:

- Provide a **Name** and optional **Description**.
- Check the box to display the description on the course page if desired.
- Expand **Appearance** settings to choose whether to show students the file size, type, and upload date.
- Decide how the file should display (e.g. embed, force download, open in new window).

## Special features

If enabled by the administrator, teachers can select a file from their Google Drive or OneDrive and display it as an "access controlled link". This lets students view the file while the teacher keeps editing capability on the original.

Slideshow presentations do not always play directly in Moodle as they would on an interactive whiteboard. A workaround is to upload the presentation to a slide-sharing site and embed it instead of uploading the raw file.
