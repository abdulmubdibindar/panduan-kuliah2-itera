# Indeks Direktori Guide

Dokumen indeks yang menjelaskan isi direktori `Guide`, tempat menyusun dokumen panduan akhir penggunaan Moodle ITERA hasil olahan dari `moodle_docs` di direktori [[Code/_index|Code]].

## Direktori

- `dosen`: bab-bab untuk **Bagian I — Panduan untuk Dosen** ([[dosen/_index|indeks bab dosen]]).
- `asisten`: bab untuk **Bagian II — Panduan untuk Asisten** ([[asisten/_index|indeks bab asisten]]).
- `mahasiswa`: bab-bab untuk **Bagian III — Panduan untuk Mahasiswa** ([[mahasiswa/_index|indeks bab mahasiswa]]).
- `assets`: aset visual, merek, dan konfigurasi Typst tingkat root buku terpadu.
- `eksperimen-obe-cpmk`: [[07 APAPUN DICOBA/Moodle Docs (manual)/Guide/eksperimen-obe-cpmk/catatan-eksperimen|catatan QMD eksperimental]] yang ditunda sampai uji Gradebook dan tidak dirender sebagai PDF.
- `_shared`: aset visual, font, dan template Typst bersama.
- `_archive/pedoman-legacy-2026-08-20`: naskah dan konfigurasi sebelum pembangunan ulang; arsip bukan sumber isi buku baru.

## File

- [[07 APAPUN DICOBA/Moodle Docs (manual)/Guide/CONTEXT|CONTEXT]]: kontrak penulisan yang menetapkan masukan, proses, keluaran, dan pemeriksaan manusia untuk satu bagian pedoman
- [[07 APAPUN DICOBA/Moodle Docs (manual)/Guide/spec|spec]]: spesifikasi pengguna sasaran, muatan minimal, bentuk keluaran, kebijakan sumber, dan kriteria selesai
- [[07 APAPUN DICOBA/Moodle Docs (manual)/Guide/matriks-pemenuhan|matriks-pemenuhan]]: status aktif dan keterlacakan kebutuhan → sumber → sandbox → bagian buku → gambar → pemeriksaan pengguna
- [[07 APAPUN DICOBA/Moodle Docs (manual)/Guide/HANDOFF-SISA-TUGAS|HANDOFF-SISA-TUGAS]]: keadaan terakhir sandbox, artefak yang sudah tersedia, pekerjaan yang tertunda, dan urutan aman bagi agen penerus
- [[07 APAPUN DICOBA/Moodle Docs (manual)/Guide/KULIAH2|KULIAH2]]: catatan penelaahan hasil eksplorasi langsung pada situs Moodle ITERA yang menjadi penghubung antara kebutuhan lokal dan dokumentasi generik Moodle
- [[07 APAPUN DICOBA/Moodle Docs (manual)/Guide/RINGKASAN|RINGKASAN]]: arsip ringkasan dan daftar pekerjaan per 9 Juli 2026; bukan sumber status aktif
- [[07 APAPUN DICOBA/Moodle Docs (manual)/Guide/20260828-panduan-verifikasi|20260828-panduan-verifikasi]]: langkah render ulang dan pemeriksaan urutan halaman depan serta entri Bagian di Daftar Isi
- [[07 APAPUN DICOBA/Moodle Docs (manual)/Guide/20260907-handoff-group-overrides|20260907-handoff-group-overrides]]: handoff fitur Group overrides pada Assignment — fakta terverifikasi, jalur menu, struktur form, quirk cutoff, sumber korpus, dan rekomendasi penempatan di pedoman (untuk menulis sub-bagian D-07/D-09 nanti)
- `periksa-urutan-pdf.py`: pemeriksa baca-saja atas PDF terbangun — urutan halaman depan, nomor halaman tercetak, dan bookmark Bagian
